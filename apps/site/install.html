Install the Chrome extension

Five steps, about two minutes. No account, no coding. Works in Google Chrome, Microsoft Edge and Brave on a computer.

Only want to check a piece of writing? You don't need the extension: open the editor and paste it in.

  1. Download GrammarMe

    It's one zip file, about 8 MB.

    Download the extension

  2. Unzip it and keep the folder

    Open your Downloads and double-click GrammarMe-extension.zip (on Windows: right-click it, then Extract All). You get a folder called GrammarMe-extension.

    Move that folder somewhere you won't tidy away, like Documents. Chrome runs GrammarMe from it, so if the folder is deleted the extension stops working.

  3. Open Chrome's extensions page

    Copy this address, paste it into Chrome's address bar and press Enter. Web pages aren't allowed to link to it, so it has to be pasted.

    chrome://extensions

    In Edge use edge://extensions, in Brave brave://extensions.

  4. Turn on Developer mode

    Flip the Developer mode switch in the top right corner. (In Edge it's in the left menu.)

    ExtensionsDeveloper mode
    Load unpackedPack extensionUpdate

  5. Click Load unpacked and pick the folder

    Click Load unpacked, choose the GrammarMe-extension folder from step 2, and click Select. GrammarMe appears in your list of extensions.

    Load unpackedPack extensionUpdate

Try it

Reload any tab that was already open, then type in a comment box or a form on any website. Mistakes get a red underline; click one to see the fix. To keep the GrammarMe button in view, click the puzzle-piece icon next to the address bar and pin it.

"Disable developer mode extensions"? Chrome sometimes shows this for any extension that isn't from the Chrome Web Store. It's expected. Click the X to keep GrammarMe on.

Is it safe? GrammarMe reads text boxes on the pages you visit so it can check them, and it checks them on your computer. It skips password and payment fields and sends nothing anywhere. Read the privacy page or the source code.

Getting a newer version: download the zip again, replace the old folder with the new one, then click the round reload arrow on GrammarMe's card in the extensions page.

Where it doesn't work yet: Gmail, Google Docs and other rich-text editors. Use the editor for those.
